  - $\le$（小於等於）、$\ge$（大於等於）、$\approx$（約等於）皆正規化為標準 LaTeX 符號。
  - $\sqrt{\dots}$ 根號符號與二項式係數 $C^n_k$ 完整修復。
  - 期望值 $E(X)$、變異數 $\mathrm{Var}(X)$、標準差 $\sigma$、二項分布 $B(n, p)$ 符號統一。
